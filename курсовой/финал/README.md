# Курсовой проект «Ручной укупориватель на тангенсном механизме» (УКП.00.000) — финальные версии

Здесь только последние версии файлов. Рабочие материалы и прежние версии лежат в папках по датам (`курсовой/2026-…`).

| Папка | Что внутри |
|---|---|
| `ТЗ и предпроектный этап/` | Техническое задание (окончательное) и предпроектный этап (25 пунктов) |
| `Расчётная записка/` | Силовой и кинематический расчёт тангенсного механизма, v30 |
| `Прочностной анализ APM/` | Прочностной анализ деталей в APM FEM: кулиса, ползун, камень, палец D, направляющая |
| `Сборка/3D-сборка укупоривателя.html` | 3D-анимация сборки и работы механизма — открывается двойным щелчком в браузере, без интернета |
| `Сборка/Инструкция по сборке.html` | Инструкция по печати и сборке по шагам — тоже самостоятельный файл |
| `Сборка/Детали для печати/` | 11 файлов STL (мм) для 3D-печати: 10 деталей укупоривателя + ключ-шестигранник S5 под винт М10; резьба М10 × 1,5 на пальце, гайке и винте — настоящая; отверстия кулисы и ползуна Ø10,6 — с зазором 0,3 мм на ось O и палец Ø10 |
| `Сборка/Модели КОМПАС/` | Сборка `УКП.00.000 Укупориватель.a3d` и детали (`Детали/`, ключ — отдельной деталью, в сборку не входит) — КОМПАС-3D v25; ссылки на детали относительные, папку можно копировать целиком |

Материалы деталей (по напряжениям из APM FEM — самый простой материал, который выдерживает): кулиса, ползун, стойка — Ст3сп;
камень и направляющая — сталь 45; палец D — сталь 40Х; кожух — АБС-пластик.
