# Курсовой проект «Ручной укупориватель на тангенсном механизме» (УКП.00.000) — финальные версии

Здесь только последние версии файлов. Рабочие материалы и прежние версии лежат в папках по датам (`курсовой/2026-…`).

| Папка | Что внутри |
|---|---|
| `ТЗ и предпроектный этап/` | Техническое задание (окончательное) и предпроектный этап (25 пунктов) |
| `РПЗ/` | Расчётно-пояснительная записка (docx + pdf, 47 стр.): оформление v13 + правки 21.11 по замечаниям — тангенсный механизм Артоболевского во введении, ссылки на источники (24), эргономика по ССБТ, схема без чисел (рис. 2) и с размерами (рис. 16). Руководитель — Подчасов Е.О. |
| `Презентация/` | Презентация для защиты, 13 слайдов по структуре преподавателя (pptx + pdf): «постановка — результат», силовой по звеньям, P(t), сечения, детали до/после; текст доклада — в заметках к слайдам |
| `Расчётная записка/` | Полный силовой и кинематический расчёт тангенсного механизма, v30 (с пояснениями и приложением А) |
| `Прочностной анализ APM/` | Прочностной анализ деталей в APM FEM: кулиса, ползун, камень, палец D, направляющая |
| `Сборка/3D-сборка укупоривателя.html` | 3D-анимация сборки и работы механизма — открывается двойным щелчком в браузере, без интернета |
| `Сборка/Инструкция по сборке.html` | Инструкция по печати и сборке, 11 шагов (ползун сверху в направляющую-«стул», палец через ползун, головка на клей) — самостоятельный файл |
| `Сборка/Инструкция по сборке и эксплуатации.pdf` | Бумажная инструкция (А4, 9 стр.) в стиле мебели/конструкторов: 12 деталей, 11 шагов картинками, закупоривание, неполадки |
| `Сборка/Детали для печати/` | 12 файлов STL (мм) для 3D-печати: 11 деталей укупоривателя (ползун — из двух частей: 6 верх и 6а головка на клей; направляющая — с полкой Ø8,6 под шток) + ключ-шестигранник S5 (шестигранник 4,85 — 21.11, напечатанный 4,6 проворачивался); резьба М10 × 1,5 на пальце, гайке и винте — настоящая; отверстия кулисы и ползуна Ø10,6 — с зазором 0,3 мм |
| `Сборка/Модели КОМПАС/` | Сборка `УКП.00.000 Укупориватель.a3d` и детали (`Детали/`, ключ — отдельной деталью, в сборку не входит) — КОМПАС-3D v25; ссылки на детали относительные, папку можно копировать целиком |

Материалы деталей (по напряжениям из APM FEM — самый простой материал, который выдерживает): кулиса, ползун, стойка — Ст3сп;
камень и направляющая — сталь 45; палец D — сталь 40Х; кожух — АБС-пластик.
