# Часть 2 — что вводить в КОМПАСе (модуль «ЧПУ. Токарная обработка»)

Пошагово с картинками — `Инструкция_Часть2_КОМПАС_ЧПУ_токарная.docx`. Ниже — только мои числа.

**Модель:** `КОМПАС/Вал — токарная часть (для ЧПУ).m3d` (КОМПАС-3D v25; уже есть ЛСК «ЛСК ЧПУ (торец шейки 1)» на свободном
торце шейки ⌀53, ось Z — по оси вала). Шестигранник в этой модели — цилиндром ⌀127,02 (как велел преподаватель).

| Окно | Что ввести |
|---|---|
| Система ЧПУ | ЛСК ЧПУ (торец шейки 1), постпроцессор **ISO** → галочка |
| Заготовка | поверхность — только шейка ⌀53: **H = 6** мм (припуск на сторону), S1/S2 = 0 → галочка |
| Приспособление | Патрон ГОСТ 2675; зажим за шейку ⌀65 (дальний конец), диаметр зажима 65, исполнение под ⌀65; вылет — чтобы ⌀127 не лез в кулачки |
| Зона безопасности | диаметр больше патрона (кулачки снаружи красных плоскостей) |
| Инструмент | «Резец проходной» правый → **φ = 90°, φ1 = 10°**, назвать «Резец упорный» |
| Операция «Многопроходная» | поверхность — шейка ⌀53; резец упорный (автоподбор снять); цикл «Многопроходный токарный», **глубина за проход 0,8**; перебег 0 (до уступа) |
| Режимы резания | **подача 0,05 мм/об, n = 586 об/мин, стойкость 45 мин**, СОЖ выкл. |
| Проверка | статистика: основное время — сравнить с расчётом 5,32 мин |
| Визуализация | запись видео (Claude может писать экран ffmpeg по команде) |
| Эскиз перехода | шероховатость → **Rz 10** |
| Программа ЧПУ | «Промежуточный код» → .txt |

Отчёт: `Отчёт/ДевяткинДА_РК6-__Б_IV-2837495935-6635-6-4_<дата>_V1.docx` — пересобрать `py расчёт/report.py РК6-XXБ`
после того, как вставим скриншоты Части 2 (места помечены красным).
