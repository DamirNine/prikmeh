Все формулы, которые добавляю в документы курсового (и дальнейшие разделы), набирать в LaTeX и вставлять настоящими формулами Word (OMML), а не строками текста шрифтом Cambria Math.

**Why:** пользователь 02.11.2026 попросил переделать все формулы «красиво через LaTeX» (сделано в v18), затем: «все следующие формулы тоже в LaTeX делай».

**How to apply:** инструмент — `курсовой/2026-11-02/omml.py`: `math_paragraph(latex, sz=28)` для нового абзаца-формулы, `replace_with_math(p, latex)` для замены. Цепочка latex2mathml 3.77.0 → правка MathML → `C:\Program Files\Microsoft Office\root\Office16\MML2OMML.XSL`. Конвенции: `\varphi`, `\varepsilon`, `\operatorname{tg}`, русские индексы `_{\text{ук}}`, десятичная запятая как есть (`1,05`), `{26,55}^{2}` для степени дробного числа, `\cdot` для умножения, реакции `R_{10}^{x}`, инерция `\Phi`. Длинные формулы делить на строки (ширина текста 16,5 см при 14 пт). LaTeX-строки не передавать через bash heredoc (портятся `\\`, `\t`) — писать файлом через Write. Пустые скобки на телефоне — особенность просмотрщика, пользователь сказал «с формулами всё норм». Связано: [[project-прикмех-курсовой]].
