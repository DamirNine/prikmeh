## Про масштаб векторов на рисунках (важно, не баг)
Деления осей (5, 10, 24…) — это КООРДИНАТЫ точки (единицы длины). Векторы V (=16π≈50)
и a (=96π²≈947) имеют другие единицы и огромны, их нельзя отложить в той же шкале.
Поэтому скорость/ускорение нарисованы в отдельном уменьшенном масштабе (sV=0.18, sA=20/96π²):
стрелка показывает НАПРАВЛЕНИЕ, истинная величина — в подписи. Длина стрелки ≠ число на оси.
Внутри одного рисунка компоненты пропорциональны (a_r:a_θ=18.8:1). Пользователь это принял,
менять не просил. Был баг: при sV=0.40 стрелка V (~20) вылезала за ylim=12 и не рисовалась —
исправлено уменьшением до sV=0.18 (~9 ед.).

Параметр `SCALE` в начале `redraw.py` — можно покрутить, если понадобится ещё мельче/крупнее.

## Технические заметки по управлению Desmos через JS API (Playwright CDP)

На странице www.desmos.com/calculator доступен `window.Calc` — внутренний API калькулятора (setExpression/setExpressions/setMathBounds/asyncScreenshot/getState/expressionAnalysis работают).

Грабли:
- Функции `vector(...)` и `segment(...)` НЕ поддерживаются на этой странице (ошибка "калькулятор не поддерживает функцию"), даже с `authorFeatures`/`forceEnableGeometryFunctions` включёнными. Вместо вектора — рисовать вручную: "вал" как параметрическую прямую `(x1+(x2-x1)t,y1+(y2-y1)t)` + треугольник-наконечник через `\operatorname{polygon}((x,y),(x,y),(x,y))` (это работает).
- Параметрическая переменная ОБЯЗАТЕЛЬНО должна называться `t` — любая другая буква (`u`,`s`,`r`...) даёт ошибку "слишком много переменных", даже если задать domain явно. При этом разные независимые кривые могут все использовать `t` одновременно без конфликта (каждая своя область видимости).
- Domain параметрической кривой надо задавать ОТДЕЛЬНЫМ вызовом `setExpression({id, domain:{min,max}})` ПОСЛЕ создания самой кривой (создание+domain в одном вызове иногда не применяется).
- Чтобы точка была невидима, но её label остался виден на скриншоте — НЕ `pointOpacity:0`, а `pointSize:0, pointOpacity:1` (opacity:0 скрывает и точку, и подпись).
- `asyncScreenshot` по умолчанию не включает подписи (label) — нужен явный параметр `showLabels:true`.
- Функции `\cos`,`\sin` и т.п. ОБЯЗАТЕЛЬНО с бэкслешем в latex; при передаче через `node -e "..."` в Bash бэкслеши легко теряются — писать .cjs файл через Write, не инлайн.
