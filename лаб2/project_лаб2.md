## Работа 2 — Анализ и синтез механизма с выстоем на базе КПМ

**Цель:** подобрать параметры внеосного КПМ (l1, l2, exs), обеспечивающие заданный ход ползуна, коэффициент скорости Kv и долю выстоя.

### Вариант (шифр): **9-7-6**
| Параметр | Строка шифра | Значение |
|----------|-------------|---------|
| Ход h    | 9           | **250 мм** |
| Kv       | 7           | **1,3** |
| Доля выстоя | 6        | **14%** |

### Ключевые формулы (из методички Подчасова):
- Начальное положение (φ=0): A(0,0), B(l1,0) в плоскости YZ
  - Кривошип при φ=0 направлен в сторону +Y
  - Ползун C: y_C = exs, **z_C = −l2·√(1−((l1−exs)/l2)²)**
- При l1=0.5, l2=1.5, exs=0.2: **z_C = −1.46969 м**
- Условие полного оборота: l1 < l2 − |exs|
- Kv = (180° + θ) / (180° − θ), где θ = (θ_пр − θ_обр)/2
- Выстой: участки, где |v| < 10% от max|v|

### Исходные параметры модели для перебора:
- l1=0.5, l2=1.5, exs=0.2 (начальные)
- Пример из методички: l1=0.5, l2=0.7, exs=0.1 → Kv≈1.38, выстой≈14%, ход≈1.022 м → нам нужен Kv=1.3 (чуть меньше)

### Система координат UM Lite (из методички, Рис.2):
- **X** — ось вращения кривошипа
- **Y** — горизонталь (направление внеосности)
- **Z** — вертикаль (ось движения ползуна, вниз = −Z)
- Гравитация: `gravityz=-1`

### Шарнирные векторы (из Рис.13 методички):
- **Ground Vector1**: точка (0,0,0), ось X — для вращательной пары кривошипа
- **Ground Vector2**: точка (0,exs,0), ось Z — для поступательной пары ползуна
- **Body1 (Crank)**: vector в (0,0,0) и в (0,l1,0), ось X
- **Body2 (Rod)**: vector в (0.1,l1,0) и в (0.1,exs,z_C), ось X
- **Body3 (Slider)**: один vector, ось Z

### Шарниры (4 шт., из Рис.14 методички):
- **j1** Body1→Ground: вращательный, **входной (заданная функция времени)**, ω=2π рад/с
- **j2** Body1→Body2: вращательный, автопозиционирование
- **j3** Body3→Body2: вращательный, автопозиционирование, **cut=true** (замыкание контура)
- **j4** Ground→Body3: поступательный, автопозиционирование

### Процедура анализа (из методички):
1. Время интегрирования = 1 с (один оборот при ω=2π)
2. Открыть Графики: Кинематика → Body3 → Координата Z (положение) + Скорость Z
3. Экспортировать (Ctrl+T) → txt-файл с двумя столбцами: t, v:z(Body3)
4. Найти: max|v|, участок выстоя (|v| < 0.1·max|v|)
5. Пересчитать θ через время → Kv

## Примечания из эталонного КПМ (Кривошипно-ползунный механизм.umd)
- GO типа "Звено" в UMD = CYLINDER + ELLIPSOID (нет специального типа LINK)
- BAR = ползун (Box-shape)
- Первый tc в joint = offset от bd1 до точки шарнира; последний tc = offset от точки шарнира до начала bd2
- Структура шарнира: tc → DOF(rv/rt/tv) → rc → tc(0,0,0) → rc → tc(return)
